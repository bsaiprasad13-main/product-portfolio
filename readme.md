# Sai Prasad — Product Builder Portfolio

This repository contains the source code for my personal portfolio website. I am a B.Tech Student at IIT Madras, pursuing a path in Product Management.

## Overview

The portfolio is a single-page HTML website (`index.html`) built with raw HTML and CSS. It showcases my shipped projects, experience, and leadership roles.

### Key Sections
- **About:** Background in Engineering Physics and transition to Product Management.
- **Shipped Projects:** Highlights real projects with actual users, including CampusGuide, Free Rooms PWA, a Mutual Fund RAG Chatbot, and an AI Agent for Weekly Product Reviews.
- **Experience:** Details my roles at NextLeap, SpandanAI, and The Startup School.
- **Leadership:** Showcases my experience as a Super Coordinator for Saarang and as a Cricket captain.

## Technologies Used
- HTML5
- CSS3 (Custom properties, Flexbox, CSS Grid, Responsive Design)
- Vanilla JavaScript (for dynamic elements like the build log ticker)
- Fonts: Space Grotesk, Inter, IBM Plex Mono

## How to View

Simply open `index.html` in any modern web browser to view the portfolio locally.
